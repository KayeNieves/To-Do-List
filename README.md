# ✅ JavaScript To-Do List

A **fully functional to-do list** built using **HTML, CSS, and JavaScript** with a clean, intuitive interface and essential task-management features, designed for organizing daily tasks easily.

---

## Features

### Basic Controls
- `Add` – adds a new task to the list.
- `Complete` – marks a task as done.
- `Delete` – removes a task from the list.

### Task Tracking
- Displays all tasks in a clear list.
- Shows completed tasks with a strike-through.
- Updates the list in real time.

### Additional Features
- `Clear All` – removes every task at once.
- Displays the number of remaining tasks.
- Prevents adding empty tasks.

---

## How It Works

The to-do list uses **JavaScript DOM manipulation** to create, update, and remove tasks dynamically without reloading the page.

**Example Usage:**
1. Type a task in the input field.
2. Press `Add` to place it in the list.
3. Click a task to mark it as completed.
4. Press `Delete` to remove a single task.
5. Press `Clear All` to empty the whole list.

---

## Technologies Used
- **HTML** – structures the to-do list interface.
- **CSS** – styles the layout and design.
- **JavaScript** – handles task functionality and user interactions.
